# 使用電子發票承諾書

> **受文機關**：財政部臺北國稅局中正稽徵所  
> **立承諾書人**：奧銳有限公司（統一編號：00015555）  
> **負責人**：王世全

---

本公司為配合政府推動電子發票政策，提升營運效能並落實節能減碳，申請自建 Turnkey 系統使用電子發票（含 B2B 營業人對營業人、B2C 營業人對個人）。本公司願恪遵各項稅法及主管機關之規定，特具承諾書，承諾事項如下：

### 第一條（法令遵行義務）
本公司承諾於電子發票之開立、傳輸、交付、作廢、銷貨退回或折讓、及保存等全流程作業，悉依《加值型及非加值型營業稅法》、《統一發票使用辦法》、《電子發票實施作業要點》及相關法令規定辦理。

### 第二條（資料正確性與時效承諾）
一、 電子發票及相關訊息均依真實交易內容翔實開立，絕無虛偽不實或偽造、變造情事。  
二、 開立對非營業人（消費者）之電子發票，承諾於開立後 **48 小時內**上傳至財政部電子發票整合服務平台存證；開立對營業人（B2B）之電子發票或交換訊息，承諾於規定時限內上傳或完成確認。  
三、 發生發票作廢、折讓或註銷時，承諾即時登錄並依限上傳平台，絕不延遲隱匿。

### 第三條（消費者權益保障承諾）
一、 尊重消費者選擇使用財政部核准之共通性載具（如手機條碼、自然人憑證）、各類載具或捐贈碼之權利，不得拒絕受理。  
二、 於每期統一發票開獎後，對未索取紙本發票且未歸戶之消費者，承諾積極辦理中獎通知並提供兌獎管道，絕不侵害消費者兌獎權益。  
三、 妥善保護消費者個人資料及交易隱私，絕不違法利用或洩漏。

### 第四條（系統安全與保存義務）
一、 確保自建 Turnkey 傳輸系統與發票開立系統之資訊安全，定期更新維護並依規定妥善保管工商憑證與金鑰，防止未授權存取或竄改。  
二、 電子發票存根檔及各項交易紀錄，承諾依法令規定妥善保存至少 **5 年**，並隨時配合國稅稽徵機關之調閱查核。

### 第五條（違約責任）
本公司若有違反上述承諾事項或相關法令之情事，願依法接受主管機關依加值型及非加值型營業稅法及稅捐稽徵法相關規定議處，並自願承擔一切法律及行政責任。
